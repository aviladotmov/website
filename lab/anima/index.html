    How it works

    Animov Studio runs in your browser. Nothing is uploaded: your files stay on your computer.

    Your files
    • in project Images, GIFs and audio up to 40 MB, and everything you make here (pasted images, drawings, voice-overs, storyboard frames) are saved inside the project file.
    • linked Videos and files larger than 40 MB stay where they are. The project saves their names and remembers where they are. Do not move, rename or delete them.
    • To send everything to someone else, use Export › Project with media.
    • Right-click a file in the Media panel to rename it (only inside the project; the file on disk keeps its name), relink it, replace it or move it to a folder.
    Offline media

    If a linked file is moved, renamed or deleted, it shows up in red as offline. The app asks you to find it as soon as you open the project. Search a folder finds the files by name, subfolders included.

    Saving
    • The project is the .animov file (its name is shown at the top). The sequence is the film you edit inside it (Sequence 01).
    • Ctrl+S saves the project as one .animov file. To open it, drag it onto this window or use File › Open.
    • While you work, a recovery copy is kept in this browser, 20 seconds after each change and when you leave the tab. If the tab closes or crashes, recover it from the start screen. It does not replace saving.

      More you can do
      • Export the film as MP4, a storyboard PDF (cover, logo, footer), a script PDF or XML for Premiere and DaVinci.
      • Notes (scene name, version, action, voice-over, on-screen text) can be burned into the MP4 with timecode, or go into the XML as markers or as an overlay on V2.
      • Script view: one row per scene (frame, video, audio), editable. Drag a row to reorder.
      • Paste a script table from Word, Google Docs, Excel or Sheets with Ctrl+V: you choose what each column is, and each row becomes a card (or fills the cards you have).
      • Draw a frame on a blank card, with ready-made assets.
      • On-screen text: type it in the scene's Storyboard notes, then pick font, position and size in the Inspector.
      • Audio tracks have a type. VO, SFX and SCENE (green) go with their scenes: a clip belongs to the scene where it starts, and moves, trims and deletes with it. MUSIC (blue) stays fixed in time. Rename a track with a double-click; change its type with a right-click. Arm a track (round button) to record on it with R.
      • Transitions: select a scene and choose how it comes in (cut, dissolve, dip to black). The first scene can fade from black and the last one fade to black.
      • Voice-over speed (Portuguese, English or your own) is in the sequence settings (gear icon).
      • Rename any scene: double-click its name.
      • Import an image sequence in numeric order (File › Import image sequence).
